Summarise Privacy Policy

Summarise is a macOS app and desktop widget for personal productivity. It helps users view a private daily summary of Gmail, Calendar, tasks, and related information.

Summarise requests read-only Gmail access. Gmail data is used only to display inbox counts, important unread counts, senders, and subject summaries inside the user's own app and widget.

Summarise does not sell user data, share Gmail data with third parties, send email, delete email, or modify Gmail content.

Google sign-in tokens are stored locally using macOS Keychain. Users can disconnect Gmail in the app at any time.
