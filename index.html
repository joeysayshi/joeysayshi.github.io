Summarise

Summarise is a macOS desktop widget and companion app that helps users see a concise daily briefing from Gmail, Calendar, tasks, and other personal productivity sources.

Privacy Policy Terms of Service Contact

Purpose of the app

Summarise connects to a user's Gmail account with permission and read-only access so it can display inbox counts, important unread messages, and recent message summaries in a private macOS dashboard and desktop widget.

The app is designed for personal productivity. It does not send email, modify Gmail data, sell user data, or share Gmail data with third parties.

Data access

Summarise requests read-only Gmail access. The app uses this access to show email information inside the user's own Mac app and widget. Sign-in tokens are stored locally using macOS Keychain.
